# Address Book in Python

## Project Topic
Development of an Address Book Application Using Python

## Description
A menu-driven Python application for storing and managing contact information.

## Features
- Add Contact
- View Contacts
- Search Contact
- Update Contact
- Delete Contact
- Input validation
- Permanent JSON file storage

## Technologies
Python 3, JSON, File Handling, Git and GitHub

## How to Run
Open a terminal in the project folder and run:

    python main.py

## Four Modules
1. Project Setup and Menu
2. Add and View Contacts
3. Search, Update and Delete
4. Validation, Storage and Testing

## Future Scope
GUI using Tkinter, SQLite/MySQL database, login system, import/export and web version.
